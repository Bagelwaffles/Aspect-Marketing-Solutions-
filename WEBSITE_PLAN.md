## 1. Strategic Overview

### Mission
Aspect Marketing Solutions delivers AI-powered marketing automation that converts visitors into customers 24/7 through intelligent agents, integrated workflows, and real-time optimization.

- **Tertiary:** Solopreneurs and creators needing scalable content and lead generation

### Core Value Proposition
**"Your marketing team that never sleeps — powered by AI agents that write, post, optimize, and convert while you focus on growth."**

## 5. Tech Stack

### Core Infrastructure
- **Hosting:** Vercel / Netlify (for static site) or DigitalOcean (for dynamic app)
- **Domain:** aspectmarketingsolutions.com (already owned via Namecheap)
- **CMS:** Notion (for blog content) or Strapi (headless CMS)
- **Analytics:** Google Analytics 4 + Plausible (privacy-friendly)
- **Heatmaps:** Hotjar or Microsoft Clarity

### Frontend
- **Framework:** Next.js (React-based, SEO-optimized)
- **Styling:** Tailwind CSS
- **Components:** Shadcn/ui or Radix UI

### Backend / Automation
- **Workflow Engine:** n8n (self-hosted on DigitalOcean)
- **CRM:** HubSpot (free tier) or Pipedrive
- **Email Marketing:** ConvertKit or Mailchimp
- **Payment Processing:** Stripe
- **Scheduling:** Calendly

### AI Integration
- **LLM:** OpenAI GPT-4 (via API)
- **Image Generation:** DALL-E 3 or Midjourney (via API)
- **Voice/Video:** ElevenLabs (text-to-speech), Synthesia (video)

## 7. Integration with AspectAI Core Platform

### How the Website Connects to AspectAI/Overmind
- **AspectAI (Core Agent):** Powers the backend automation, content generation, and workflow orchestration
- **Overmind (Orchestration Layer):** Manages multi-agent coordination, task delegation, and real-time decision-making
- **Website Role:** Acts as the public-facing marketing layer that drives lead acquisition and customer onboarding

### Data Flow
1. **Lead Capture:** Website form → n8n workflow → HubSpot CRM → AspectAI agent
2. **Content Publishing:** AspectAI generates blog post → Sends to Notion → Website pulls via API → Publishes
3. **User Onboarding:** User signs up → Overmind triggers welcome sequence → AI agent personalizes experience
